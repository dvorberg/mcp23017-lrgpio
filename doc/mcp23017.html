mcp23017

Access a MCP23017 “IO Expander” through the i2c wrapper provided by rgpio or lgpio.

This is a learning project of mine to understand I2C programming better, and an API design exercise. I plan to use this in “production” on my model railway, but I will only test it is as far as I use it. Your milage may vary. Patches welcome.

The MCP23017 “GPIO Expander” is interfaced in IOCON.BANK = 0 mode. This mode allows read and write operations to single byte registers to access two banks (A and B) of eight GPIOs each.

Overview

  • The Expander class provides connectivity and access to the Expander’s banks of eight GPIOs each, bank_a and bank_b.
  • The Bank class procides access to the bank’s configuration registers through properties (iodir_is_input, pin_polarity_is_reversed, interrupt_on_change, default_comparison_values, interrupt_compare_to_default, internal_pull_up_is_active, interrupt_flags, interrupt_captured, gpios, output_latches) and also read() and write() methods that set and get GPIO bin status as one would expect. A Bank acts like an eight-tuple of Pins. The register properties correspond to the acrual registers. The datasheet is quoted extensively below.
  • The Pin class represents a pin on a bank and allows read() and write() as one might expect. The class also provides access to the Pin’s Bank’s configuration registers. All values will go through the Registers on the corresponding Bank and will trigger i2c read and/or write operations, if needed.
  • The Byte class subclasses int and provides helper functions to read and manipulate single bits. You will interact with registers on the banks almost exclusively through this class. Everything should be self-explainatory, though.
  • The (Cached-, ReadOnly-) Register classes and the (ReadOnly-) PinConfig classes implement Python’s property protocol to facilitate access to the device’s configuration and data. It is in the Register class that the only calls to i2c IO functions are actually made. There are exactly two lines in this program where this happens, one for reading (in __get__()) and one for writing (in __set__()).

The MCP23017 datasheet is quoted extensively below, explaing the configuration registers. For the somewhat complex dependencies between the registers governing interrupt operation, I refer you to that document. The registers to controll the internal pull-up resistors and logical pin reversal are easily understood. In many contexts in which I use the device, this saves me resistors and soldering. Nice!

 90class Byte(int):
 91    """
 92    A byte is an integer that stores a pattern of 8 bits. It may be
 93    initialized with a ByteSpec which may be either:
 94    * an 8-tuple of bools,
 95    * a regular integer
 96    * or a bool.
 97    A bool will be regarded as eight 1s, for True, or eigth 0s, for False.
 98    For all other input values, a TypeError will be raised. 
 99
100    A Byte is iterable and will yield eigth boolean values.<br>
101    A Byte has allows indexed access like an 8-tuple of bools.
102
103    The string representation of a Byte is a binary integer literal:
104    repr(b) = str(b) = "0b01010101".
105    """
106    def __new__(cls, b:ByteSpec):
107        if type(b) is tuple:
108            i = 0x00
109            for bit, a in enumerate(b[:8]):
110                if a:
111                    i = i | (0x01 << bit)
112        elif isinstance(b, int): # isinstance() takes inheritance into account.
113            i = b & 0xff
114        elif type(b) is bool:
115            if b:
116                i = 0xff
117            else:
118                i = 0x00
119        else:
120            raise TypeError("Can’t construct Byte from " + repr(b))
121                
122        return super().__new__(cls, i)
123    
124    def __iter__(self):
125        """
126        Yield the bit-pattern as eight bools.
127        """
128        if hasattr(self, "_tuple"):
129            yield from iter(self._tuple)
130        else:
131            for a in range(8):
132                yield bool(self & (0x1 << a))
133
134    def __getitem__(self, idx) -> bool:
135        """
136        Access the bits as if this were an eight-tuple of bools. 
137        """
138        if not hasattr(self, "_tuple"):
139            self._tuple = tuple(self)
140        return self._tuple[idx]
141
142    def __repr__(self) -> str:
143        """
144        A Byte is represented as a Python binary literal with leading 0s. 
145        """
146        return "0b" + "{:08b}".format(self)
147
148    def set_bit_to(self, bit:int, value:bool):
149        """
150        Return a copy of self with the specified `bit` set to `value`. 
151        """
152        mask = 0x01 << bit
153        if value:
154            new = self | mask
155        else:
156            rmask = 0xff - mask
157            new = self & rmask
158            
159        return Byte(new)
160
161    def set_bit(self, bit:int):
162        """
163        Return a copy of self with the specified `bit` set.
164        """
165        return self.set_bit_to(bit, True)
166        
167    def delete_bit(self, bit:int):
168        """
169        Return a copy of self with the specified `bit` deleted.
170        """
171        return self.set_bit_to(bit, False)
172
173    def get_bit(self, bit:int) -> bool:
174        """
175        Get the state of a single bit.
176        """
177        return bool(self & (0x01 << bit))

179class Expander(object):
180    """
181    A MCP23017 in IOCON.BANK = 0 mode. This mode allows read and write
182    operations to single byte registers to access two banks (A and B)
183    of eight GPIOs each. 
184    """    
185    def __init__(self, sbc:SBC, i2c_bus:int, address:int):
186        """
187        Args:
188            sbc: Either the lgpio module, a rgpio.sbc instance or a
189                wrapper thereof.
190            i2c_bus: Bus number
191            address: The device’s address on that bus. 
192        """
193        self._sbc = sbc
194        self._handle = sbc.i2c_open(i2c_bus, address)
195        
196        self.bank_a = Bank(self, 0)
197        self.bank_b = Bank(self, 1)
198        
199    def __del__(self):
200        self._sbc.i2c_close(self._handle)
201
202    def write_byte_data(self, register:int, value:int):
203        self.sbc.i2c_write_byte_data(self._handle, register, value)
204
205    def read_byte_data(self, register:int) -> int:
206        return self.sbc.i2c_read_byte_data(self._handle, register)

245class CachedRegister(Register):
246    """
247    This is meant for configuration registers. We assume exclusive
248    access to the chip. We cache configuration values written and
249    return them as current values if requested. If no value has been
250    written, yet, current values are read from the chip.
251    """
252    def __get__(self, bank:BankBase, owner:object) -> Byte:
253        ret = self.get_cache(bank)
254        if ret is None:
255            ret = super().__get__(bank, owner)
256            self.set_cache(bank, ret)
257        return Byte(ret)
258
259    def __set__(self, bank:BankBase, value:Byte):    
260        super().__set__(bank, value)
261        self.set_cache(bank, value)
262        
263    @property
264    def _cache_name(self):
265        return f"_{self._name}_cache"
266    
267    def get_cache(self, bank:BankBase):
268        return getattr(bank, self._cache_name, None)
269
270    def set_cache(self, bank:BankBase, value:int):
271        setattr(bank, self._cache_name, value)

427class PinConfig(object):
428    """
429    A bit of a configuration register.
430
431    This class implements Python’s property protocol. 
432    
433    Each change will trigger a (cached) read from the register and a
434    write. To change multiple bits in a register use the registers
435    directly.
436    """
437    def __set_name__(self, pin:PinBase, name:str):
438        """
439        The name of the Pin’s boolean property must correspond to the
440        (Cached or ReadOnly) Register in the Bank class. This is hard coded
441        here. The Bank class may use plural.
442
443        BTW: This is not an efficiancy issue. This constructor is called at
444        import time.
445
446        Raises:
447           NameError: If the Bank class does not contain a corresponding
448               register.
449        """
450        for n in (name, name + "s", name + "es",):
451            if n in Bank.__dict__:
452                self.register = Bank.__dict__[n]
453                break
454        else:
455            raise NameError(repr(name))
456
457    def __get__(self, pin:PinBase, owner:object) -> bool:
458        return bool(self.register.__get__(pin.bank, pin) & pin.mask)
459
460    def __set__(self, pin:PinBase, value:bool):
461        old = self.register.__get__(pin.bank, pin)
462        self.register.__set__(pin.bank, old.set_bit_to(pin.no, value))

  • a regular integer
